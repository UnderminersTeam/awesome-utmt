# Awesome UndertaleModTool [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A community-sourced and curated list of UndertaleModTool scripts, game-specific data, and other resources.

[UndertaleModTool](https://github.com/UnderminersTeam/UndertaleModTool) is an application designed for modding, decompiling, and unpacking Undertale (and other GameMaker games!).
