# Contribution Guidelines

In order to contribute resources to this list (or to update existing resources), please review the following information.

## Pull Requests

- Links must be related to UndertaleModTool and other tools/libraries that it interacts with.
- Avoid any content related to full GameMaker project decompilation, or anything else likely to cause issues.
- Ensure links are not already present on the list.
- Provide a short description for each linked resource.
- Provide compatible/tested UndertaleModTool (or other tool/library) versions, where applicable.
- Place new links at the bottom of the category it belongs to.

## Issues

- For any errors that need correcting, issues may be created. However, for trivial fixes, pull requests are preferred.
- Suggestions for additional categories and the overall repository are welcome.
- Owners/authors of resources may request removal of their link.
